# docExtractor

QNAP NAS上で漫画・ドキュメント系アーカイブを整理するための軽量Webアプリです。

`mangaOrganize.py` の処理フローをベースに、次を安全かつ高速に行うことを目的とします。

1. 指定フォルダから `.zip` / `.rar` を検出
2. 一時ワークスペースへ展開
3. 内容を検証してZIPへ再圧縮
4. ファイル名からシリーズ名・巻数を推定
5. 同一シリーズのZIPをシリーズフォルダへ整理
6. Web UIからスキャン、プレビュー、実行、進捗確認

対象機種の初期ターゲットは **QNAP TS-253Be (x86_64)** です。

詳細設計と実装は feature branch / Pull Request で進めます。
